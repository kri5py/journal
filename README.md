# journal

A personal journal in a single HTML file: chat with an AI best-friend buddy, write entries, see mood over a week/month, and a "world" tab with people, topics, events, goals and good things.

It is built to run as a Claude artifact (it uses the artifact runtime's `sample`, `db` and `user` capabilities), so the AI chat and saved entries only work there. Opened as a plain file it falls back to browser storage with no AI.
